# Optimize

Ferramenta de otimização para Windows 10 e 11: limpeza, análise de disco, programas, inicialização, Modo Jogo, drivers e mais.

## Download

Baixe o instalador mais recente em **[Releases](../../releases/latest)** (arquivo `OptimizeSetup-x.y.z.exe`).

Depois de instalado, o Optimize avisa sozinho quando houver uma versão nova (Ajustes → Atualizações).

## Aviso do Windows na instalação

O instalador ainda não tem assinatura digital. O Windows pode mostrar **"O Windows protegeu o computador"**:
clique em **Mais informações → Executar assim mesmo**.

Este repositório guarda apenas os instaladores.
